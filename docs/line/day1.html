LINE限定 1日目

自分の会社は「普通」か。
5つの数字で確かめる

残業100時間の会社に5年いた僕が、辞める前に知りたかった労務のルールを5つにまとめました。全部、リールで反応が大きかったものです。読み終わる頃に「うちは大丈夫」なら、それが一番いい。

なぜ「普通かどうか」から始めるのか

転職を考えるとき、多くの人は「次にどこへ行くか」から考えます。

でも順番が逆です。いまの会社が法律の範囲内なのかを知らないと、比べる基準がありません。

僕は5年間、朝7時半に出社して23時に帰るのを「営業ってこういうもの」だと思っていました。まわりも同じだったし、先輩は「俺の頃はもっと酷かった」と笑っていた。

比べる相手は社内の人ではなく、労働基準法と他社の求人票です。同じ部屋にいる人の意見は、何人集めても1つの意見でしかない。

ここから5つ、数字で確かめます。

1. 残業の上限は「月45時間」

残業には法律で上限があります。原則は月45時間・年360時間。これを超えるには「特別条項」という手続きが必要で、それでも超えられない線があります。

何の上限か数値中身
特別条項の年間上限年720時間休日労働を除いた時間で数える
原則の年間上限年360時間特別条項が無ければここまで
単月の絶対上限月100時間未満休日労働を含めて超えられない
複数月の平均80時間どの2〜6か月の平均でも超えられない
原則の月上限月45時間これが「45時間の壁」
45時間を超えられる回数年6回特別条項でも年6か月まで

僕の月100時間は、単月の絶対上限に触れていました。しかもそれが毎月。「忙しい時期だから」は、年6回までしか通用しません。

2. その残業代、払われていますか

残業代が出ない理由として会社がよく言うことと、法律上の扱いを並べます。

場面✗ 会社の言い分○ 法律上の扱い
みなし残業固定分を超えても出ない超えた分は追加で支払う
管理職役職者に残業代は不要名ばかり管理職には出る
朝礼始業前の準備は業務外参加が義務なら労働時間
着替え制服の着替えは自由時間社内で義務なら労働時間
持ち帰り家でやるのは自己研鑽指示があれば労働時間
休憩電話番も休憩に含める待機は休憩にならない
15分未満15分未満は切り捨てる1分単位で計算するのが原則
歩合制歩合だから残業代なし歩合制でも残業代は出る
新人研修研修は勉強なので無給参加必須なら賃金が必要
時効過ぎた分はもう請求不可過去3年分は請求できる

僕の会社は上から3つが全部当てはまっていました。みなし残業30時間分の固定額だけ、営業は「管理職扱い」、朝礼は業務外。

給与明細を実際に働いた時間で割ってみてください。時給に直すと「まあ普通かな」が消えます。僕はコンビニのバイトより低かった。

3. みなし残業の「本当のルール」

求人票の年収が高く見えるとき、みなし残業(固定残業代)が入っていることが多い。仕組み自体は合法ですが、守るべき条件があります。

論点✗ よくある説明○ 本当のルール
超えた分の扱い何時間働いても定額超過分は別に支払う義務がある
時間数の明示何時間分か書かなくてよい契約書と給与明細に明示が必要
残業しなかった月働いた分だけ差し引かれる定額なので満額支払われる
深夜と休日みなしに全部含まれる深夜と休日の割増は別に発生
設定できる上限何時間でも決められる45時間を超える設計は問題になる
求人票の年収実力の評価額だと考える残業代込みの額として計算し直す
基本給との関係基本給に含めて曖昧にできる基本給と分けて表示する
勤怠の記録定額だから記録は不要労働時間の把握は会社の義務

転職先を見るときは、求人票の年収から「固定残業代 ◯時間分 ◯円」を引いた額で比べてください。それが本当の基本給です。

4. 有給は何日あるはずか

有給休暇は勤続年数で日数が決まっています。「うちは有給が取れない」の前に、まず何日あるはずかを確認する。

勤続年数もらえる日数この年数で起きること
6年6ヶ月以上20日これが上限。以降は増えない
5年6ヶ月18日1年で2日ずつ増える時期
4年6ヶ月16日繰越と合わせ月1休める
3年6ヶ月14日2週間の連休が取れる計算
2年6ヶ月12日月1回のペースで使える
1年6ヶ月11日2年目から増え方が緩やか
6ヶ月10日入社半年で最初の付与

有給は2年で消えます。年10日以上ある人は、年5日は会社が取らせる義務があります。取らせていない会社は、その時点で法律を守っていません。

5. 辞めたときにもらえるお金

「辞めたら収入がゼロになる」と思って動けない人が多い。実際は、条件を満たせば受け取れるものがいくつもあります。

もらえるお金どこから出るか金額の目安
失業給付雇用保険賃金日額のおよそ50〜80%
再就職手当雇用保険残日数の60%または70%
傷病手当金健康保険標準報酬のおよそ3分の2
教育訓練給付雇用保険受講費の20〜70%
高年齢求職者給付金雇用保険一時金で30日または50日分
退職金会社の制度制度が無い会社もある
未消化の有給会社買い取りは義務ではない
国民年金の免除日本年金機構退職特例で申請できる

失業給付は「会社都合」か「自己都合」かで、もらえる時期と日数が変わります。長時間労働が理由の退職は、条件を満たせば会社都合と同じ扱い(特定受給資格者)になることがあります。残業の記録を取っておく理由は、ここにもあります。

5つ、確かめてみて

□ 残業は月45時間を超えていないか
□ 残業代は1分単位で全部出ているか
□ みなし残業の時間数は明細に書いてあるか
□ 有給は勤続年数どおりの日数があり、年5日取れているか
□ 辞めたときに何がもらえるか、知っているか

全部○なら、あなたの会社は「普通」です。転職を急ぐ必要はありません。

1つでも✗があったなら、それは「あなたが我慢すればいいもの」ではなく、会社が守っていない法律です。

僕はこの✗に気づいた日から、辞める準備を始めました。急に辞めたわけではありません。まず、自分が何を譲れないのかを決めるところから。

明日21時は、その「譲れないものの決め方」の話です。特典5のワークシートを手元に置いておいてください。
